使用场景 ​

场景概览 ​

LiveRecorder 适用于多种直播和录屏场景，以下是常见使用案例：

场景适用模式推荐配置
单人直播跟拍AUTO标准镜头
多机位直播AUTO/MANUAL多录制者
自动轮换跟拍AUTO快速切换
手动控制跟拍MANUAL精细控制
隐私保护模式MANUAL隐私优先

基本流程 ​

  1. 准备录制者账号 - 创建专用录制者账号
  2. 绑定录制者 - 使用 /lr bind 命令绑定
  3. 开始录制 - 录制者自动跟随目标
  4. 管理录制 - 根据需要切换目标或模式
  5. 结束录制 - 使用 /lr unbind 解绑

场景列表 ​

  • 单人直播跟拍 - 一个录制者跟拍一个主播
  • 多机位直播 - 多个录制者从不同角度跟拍
  • 自动轮换跟拍 - 录制者自动在不同玩家间切换
  • 手动控制跟拍 - 导播手动控制跟拍目标
  • 隐私保护模式 - 启用隐私保护功能

提示 ​

选择合适的模式 ​

  • AUTO 模式 - 适合综艺节目、活动跟拍
  • MANUAL 模式 - 适合需要精细控制的场景

权限管理 ​

给录制者账号单独的权限节点：

yaml
permissions:
  liverecorder.recorder:
    default: false
1
2
3

然后只给录制者账号授予权限：

/lp user CameraMan permission set liverecorder.recorder true
