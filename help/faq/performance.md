# 性能问题

关于 LiveRecorder 性能的常见问题。

## 服务器卡顿

### 问题描述

启用 LiveRecorder 后，服务器出现卡顿。

### 可能原因

1. **录制者数量过多**
   - 绑定了太多录制者
   - 每个录制者都会消耗资源

2. **视觉效果过多**
   - 启用了粒子效果
   - 启用了过多发光效果

3. **日志记录过多**
   - 日志保留数量过大
   - 频繁的数据库操作

### 解决方案

#### 减少录制者数量

```bash
# 查看所有录制者
/lr list

# 解绑不需要的录制者
/lr unbind Camera01
/lr unbind Camera02
```

**建议：** 最多 5 个录制者

#### 关闭不必要的视觉效果

```yaml
visual:
  camera-particle: false   # 关闭粒子效果
  target-glow: true        # 保留发光效果
  actionbar-enabled: true  # 保留 ActionBar
```

#### 调整日志保留数量

```yaml
privacy:
  live-logs:
    keep-count: 50         # 减少日志保留数量
```

## 内存占用过高

### 问题描述

LiveRecorder 占用过多内存。

### 可能原因

1. **日志数据过多**
   - 日志保留数量过大
   - 数据库文件过大

2. **绑定数据过多**
   - 保存了过多的历史绑定

### 解决方案

#### 清理旧日志

```yaml
privacy:
  live-logs:
    keep-count: 50         # 减少日志保留数量
```

重启服务器，插件会自动清理旧日志。

#### 手动清理数据库

```bash
# 备份数据库
cp plugins/LiveRecorder/privacy.db plugins/LiveRecorder/privacy.db.backup

# 删除并重建（会丢失所有数据）
rm plugins/LiveRecorder/privacy.db
```

## CPU 占用过高

### 问题描述

LiveRecorder 占用过多 CPU。

### 可能原因

1. **跟随计算过于频繁**
   - 每个录制者都在计算跟随
   - 计算过于复杂

2. **视觉效果渲染**
   - 粒子效果渲染
   - 发光效果渲染

### 解决方案

#### 减少录制者数量

```bash
# 解绑不需要的录制者
/lr unbind Camera01
```

#### 关闭粒子效果

```yaml
visual:
  camera-particle: false
```

#### 调整平滑系数

```yaml
camera:
  position-smooth: 0.08    # 降低位置平滑系数，减少计算频率
  rotation-smooth: 0.06    # 降低视角平滑系数
```

## 网络延迟

### 问题描述

录制者与目标之间出现网络延迟。

### 可能原因

1. **服务器性能不足**
   - 服务器负载过高
   - 网络带宽不足

2. **录制者网络问题**
   - 录制者网络不稳定
   - 录制者延迟过高

### 解决方案

#### 检查服务器性能

```bash
# 查看服务器延迟
/ping

# 查看服务器 TPS
/tps
```

#### 检查录制者延迟

```bash
/ping CameraMan
```

#### 调整平滑配置

```yaml
camera:
  position-smooth: 0.08    # 降低位置平滑系数，容忍延迟
  rotation-smooth: 0.06    # 降低视角平滑系数
```

## 最佳实践

### 性能优化

1. **限制录制者数量** - 最多 5 个录制者
2. **关闭不必要的视觉效果** - 禁用粒子效果
3. **合理的日志保留** - 50-100 条日志
4. **使用合适的配置** - 避免过高的跟随速度

### 监控性能

1. **定期检查服务器 TPS** - 使用 `/tps` 命令
2. **检查录制者数量** - 使用 `/lr list` 命令
3. **检查数据库大小** - 定期检查 `privacy.db` 文件大小

### 应急处理

1. **解绑所有录制者** - 快速释放资源
2. **重启插件** - 使用 `/lr reload` 命令
3. **重启服务器** - 如果问题严重

## 性能基准

### 推荐配置

| 服务器配置 | 录制者数量 | 视觉效果 | 日志保留 |
|:---------:|:---------:|:--------:|:--------:|
| 低配服务器 | 1-2 | 基础 | 50 |
| 中配服务器 | 3-5 | 标准 | 100 |
| 高配服务器 | 5+ | 完整 | 200 |

### 性能指标

| 指标 | 低配 | 中配 | 高配 |
|:----:|:----:|:----:|:----:|
| TPS | 18-20 | 19-20 | 20 |
| 内存占用 | < 50MB | < 100MB | < 200MB |
| CPU 占用 | < 5% | < 10% | < 15% |
