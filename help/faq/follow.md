# 跟随问题

关于录制者跟随功能的常见问题。

## 录制者画面出现瞬移

### 问题描述

录制者在跟随目标时出现瞬移，画面不流畅。

### 可能原因

1. **目标玩家频繁传送**
   - 目标使用了 `/tp`、`/home` 等传送命令
   - 目标跨世界传送
   - 目标使用末地传送门等

2. **镜头配置不当**
   - `position-smooth` 设置过高
   - `distance` 设置过小
   - 平滑系数与移动速度不匹配

3. **网络延迟**
   - 服务器延迟过高
   - 录制者网络不稳定
   - 网络丢包

### 解决方案

#### 调整镜头配置

```yaml
camera:
  position-smooth: 0.08    # 减小位置平滑系数，让移动更平滑
  rotation-smooth: 0.06    # 减小视角平滑系数，让旋转更柔和
  distance: 8.0            # 增大镜头距离
```

#### 检查网络延迟

```bash
# 检查服务器延迟
/ping

# 检查录制者延迟
/ping CameraMan
```

#### 使用调试模式

```yaml
debug: true
```

查看详细的跟随日志，找出问题根源。

## 录制者跟不上目标

### 问题描述

录制者跟随目标时跟不上，距离越来越远。

### 可能原因

1. **目标移动速度过快**
   - 目标使用了飞行模式
   - 目标使用了速度药水
   - 目标使用了骑乘工具

2. **镜头配置不当**
   - `position-smooth` 设置过低
   - `distance` 设置过大
   - 平滑系数不足

### 解决方案

#### 调整镜头配置

```yaml
camera:
  position-smooth: 0.30    # 增大位置平滑系数
  rotation-smooth: 0.20    # 增大视角平滑系数
  distance: 4.0            # 减小镜头距离
```

#### 使用更快的配置

**快速跟随配置：**
```yaml
camera:
  pitch: 25.0
  distance: 4.0
  position-smooth: 0.30
  rotation-smooth: 0.20
```

## 录制者位置不准确

### 问题描述

录制者的位置不准确，偏离预期位置。

### 可能原因

1. **镜头计算错误**
   - 俯角设置不当
   - 距离设置不当
   - 高度偏移设置不当

2. **目标朝向问题**
   - 目标快速转向
   - 目标视角变化频繁

### 解决方案

#### 调整镜头参数

```yaml
camera:
  pitch: 30.0          # 调整俯角
  distance: 5.0        # 调整距离
  height-offset: 0.0   # 调整高度偏移
```

#### 使用标准配置

**标准跟拍配置：**
```yaml
camera:
  pitch: 30.0
  distance: 5.0
  position-smooth: 0.12
  rotation-smooth: 0.1
```

## 录制者抖动

### 问题描述

录制者在跟随目标时出现抖动，画面不稳定。

### 可能原因

1. **平滑系数过高**
   - `position-smooth` 设置过高
   - 录制者过度反应位置变化

2. **视角平滑系数过高**
   - `rotation-smooth` 设置过高
   - 录制者过度反应视角变化

### 解决方案

#### 调整配置

```yaml
camera:
  position-smooth: 0.08    # 减小位置平滑系数
  rotation-smooth: 0.06    # 减小视角平滑系数
```

#### 使用平滑配置

**平滑跟随配置：**
```yaml
camera:
  pitch: 35.0
  distance: 6.0
  position-smooth: 0.06
  rotation-smooth: 0.05
```

## 录制者卡住

### 问题描述

录制者卡在某个位置不动，无法跟随目标。

### 可能原因

1. **目标玩家下线**
   - 目标玩家退出服务器
   - 目标玩家掉线

2. **录制者被限制**
   - 录制者被限制移动
   - 录制者被卡住

3. **插件错误**
   - 插件出现异常
   - 数据库错误

### 解决方案

#### 检查目标状态

```bash
# 检查目标是否在线
/lr list
```

#### 重启插件

```bash
/lr reload
```

#### 重新绑定

```bash
# 解绑录制者
/lr unbind CameraMan

# 重新绑定
/lr bind CameraMan 目标 auto
```

## 录制者传送问题

### 问题描述

录制者跟随目标传送时出现问题。

### 可能原因

1. **跨世界传送**
   - 目标跨世界传送
   - 录制者传送失败

2. **传送限制**
   - 插件阻止传送
   - 权限问题

### 解决方案

#### 检查世界设置

确保录制者可以传送到目标所在的世界。

#### 检查权限

确保录制者有传送权限：
```yaml
permissions:
  liverecorder.recorder:
    permissions:
      - minecraft.command.tp
```

## 最佳实践

### 镜头配置

根据游戏类型选择合适的镜头配置：

| 游戏类型 | pitch | distance | position-smooth | rotation-smooth |
|:--------:|:-----:|:--------:|:---------------:|:---------------:|
| PVP 游戏 | 25° | 4.0 | 0.30 | 0.20 |
| 建筑游戏 | 45° | 8.0 | 0.08 | 0.06 |
| 冒险游戏 | 30° | 5.0 | 0.12 | 0.10 |
| 休闲游戏 | 35° | 6.0 | 0.06 | 0.05 |

### 性能优化

1. **减少录制者数量** - 最多 5 个录制者
2. **关闭不必要的视觉效果** - 禁用粒子效果
3. **使用合适的配置** - 避免过高的平滑系数

### 监控和调试

1. **使用调试模式** - 查看详细日志
2. **定期检查绑定状态** - 使用 `/lr list`
3. **查看日志** - 了解跟随情况
