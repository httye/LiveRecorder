# 使用场景

## 场景概览

LiveRecorder 适用于多种直播和录屏场景，以下是常见使用案例：

| 场景 | 适用模式 | 推荐配置 |
|:-----|:--------:|:--------|
| 单人直播跟拍 | AUTO | 标准镜头 |
| 多机位直播 | AUTO/MANUAL | 多录制者 |
| 自动轮换跟拍 | AUTO | 快速切换 |
| 手动控制跟拍 | MANUAL | 精细控制 |
| 隐私保护模式 | MANUAL | 隐私优先 |

## 基本流程

1. **准备录制者账号** - 创建专用录制者账号
2. **绑定录制者** - 使用 `/lr bind` 命令绑定
3. **开始录制** - 录制者自动跟随目标
4. **管理录制** - 根据需要切换目标或模式
5. **结束录制** - 使用 `/lr unbind` 解绑

## 场景列表

- [单人直播跟拍](./single) - 一个录制者跟拍一个主播

## 提示

### 选择合适的模式

- **AUTO 模式** - 适合综艺节目、活动跟拍
- **MANUAL 模式** - 适合需要精细控制的场景

### 镜头参数建议

| 效果 | pitch | distance | follow-speed |
|:----:|:-----:|:--------:|:------------:|
| 🦅 鸟瞰视角 | 60° | 8.0 | 0.35 |
| 📹 标准跟拍 | 30° | 5.0 | 0.35 |
| 🎬 平视特写 | 10° | 3.0 | 0.40 |
| 🏃 快速跟随 | 25° | 4.0 | 0.50 |
| 🐢 慢速平滑 | 35° | 6.0 | 0.20 |

### 权限管理

给录制者账号单独的权限节点：
```yaml
permissions:
  liverecorder.recorder:
    default: false
```

然后只给录制者账号授予权限：
```
/lp user CameraMan permission set liverecorder.recorder true
```
