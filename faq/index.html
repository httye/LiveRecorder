快速解答 ​

录制者画面出现瞬移怎么办？ ​

尝试调低 position-smooth 值（如 0.08），或增大 distance 让镜头更远。如果目标玩家频繁传送，这是正常行为——插件会自动传送录制者到新位置。

录制者跟不上目标玩家怎么办？ ​

调高 position-smooth 值（如 0.30），或减小 distance 让镜头更近。

如何让录制者使用旁观者模式？ ​

在绑定录制者之前，先将录制者设为旁观者模式：

/gamemode spectator CameraMan
/lr bind CameraMan Steve auto

目标玩家下线了怎么办？ ​

插件会自动将录制者切换到其他在线目标。如果没有其他目标，跟随会暂停，录制者会收到通知。

可以同时跟拍多个目标吗？ ​

一个录制者同一时间只能跟拍一个目标。但你可以绑定多个录制者到不同目标，实现多机位效果。

如何关闭录制者的操作限制？ ​

在 config.yml 中将对应的限制项设为 false，然后执行 /lr reload。

如何禁用录制者隐身功能？ ​

在 config.yml 中设置：

yaml
privacy:
  recorder-invisible:
    enabled: false

然后执行 /lr reload。

玩家如何拒绝被直播？ ​

玩家可以使用以下方式拒绝：

# 拒绝当前的直播请求
/lr decline

# 永久拒绝被直播
/lr setprivacy decline

隐私数据保存在哪里？ ​

隐私设置和直播日志保存在 plugins/LiveRecorder/privacy.db SQLite 数据库文件中。

如何清理旧的直播日志？ ​

插件会自动保留最近 100 条日志，超出限制的会在下次启动时自动清理。也可以手动删除数据库文件（不建议）。

报告问题 ​

报告问题时，请提供以下信息：

  1. 服务器信息

    • 服务端类型和版本（Spigot/Paper, 1.16+）
    • Java 版本

  2. 插件版本

    • LiveRecorder 版本号

  3. 问题描述

    • 详细描述问题
    • 重现步骤
    • 期望行为

  4. 错误日志

    • 控制台错误信息
    • 相关配置

  5. 截图/视频

    • 问题截图或录屏
